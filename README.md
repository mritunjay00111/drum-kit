# 🥁 Drum Kit Project

A simple and interactive **Drum Kit** web application built using **HTML, CSS, and JavaScript**.  
Users can play different drum sounds using **keyboard keys** or **mouse clicks**, with visual feedback for each interaction.

---


## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and animations  
- **JavaScript (ES6)** – Logic, event handling, and audio control  

---

## 🎮 How It Works

- Each drum sound is mapped to a specific keyboard key  
- Press the corresponding key **or click** on a drum pad to play a sound  
- The active drum pad scales up briefly to give visual feedback  

---

## ⌨️ Key Mappings

| Key | Sound |
|----|------|
| A | Clap |
| S | Boom |
| D | Hi-hat |
| F | Kick |
| G | Open-hat |
| H | Ride |
| J | Snare |
| K | Tink |
| L | Tom |
